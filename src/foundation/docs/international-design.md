# International Design

다양한 언어·문화 대응을 위한 국제화 디자인 가이드.

## 원칙

- **일관된 전달** — 어느 언어로 번역해도 톤·용어·표현이 일관되게 전달되도록 설계한다.
- **로케일 형식 준수** — 시간·날짜·숫자·통화 등은 각 로케일의 표기 형식을 따른다.
- **텍스트 확장 대비** — 번역 시 텍스트 길이가 달라지는 것을 전제로 레이아웃을 설계한다.

## 상대적 시간 표기

경과 시간은 로케일별 표기 방식을 따른다. 영어는 지역명 등이 길어 공간 제약이 생기므로 시간을 한국어보다 짧게 축약 표기한다.

| 기준 | ko_KR | en_CA·en_US·en_GB | ja_JP | 비고 |
| --- | --- | --- | --- | --- |
| 매우 짧은 시간 | 방금 전 | Just now | たった今 | |
| 초 | n초 전 | ns | n 秒前 | |
| 분 | n분 전 | nmin | n 分前 | m은 거리 단위(meter·mile)로 읽힐 수 있어 min을 사용한다 |
| 시간 | n시간 전 | nh | n 時間前 | |
| 일 | n일 전 | nd | n 日前 | |
| 주 | n주 전 | nw | n 週間前 | |
| 월 | n달 전 | nmo | n か月前 | |
| 년 | n년 전 | ny | n 年前 | |

영어 축약 표기는 단수·복수 모두 같은 형태를 사용한다 (1s, 2s / 1min, 2min).

## 숫자·단위 표기

### 숫자와 단위의 순서

개수를 나타내는 단위(조회수, 좋아요 등)는 언어별로 숫자와 단위의 위치가 다르다.

| ICU Locale ID | 조회수 예시 | 후기 예시 (단수) | 후기 예시 (복수) | 비고 |
| --- | --- | --- | --- | --- |
| ko_KR | 조회수 3만 | 후기 1개 | 후기 3개 | |
| en_CA·en_GB·en_US | 30K views | 1 review | 3 reviews | 복수형을 구분한다 |
| ja_JP | 閲覧数 3 万 | レビュー 1 件 | レビュー 3 件 | |

### 큰 수 표기

- 한국어는 만(10,000) 단위로 수를 세고, 만 미만 구간의 축약에는 천 단위를 쓴다. 영어는 천(1,000) 단위로 수를 센다.
- 한국어의 억(100,000,000)은 영어에 대응 단위가 없어 100M으로 표기한다.

| Number | ko_KR | en_CA·en_GB·en_US | ja_JP | 비고 |
| --- | --- | --- | --- | --- |
| 123 | 123 | 123 | 123 | |
| 1,230 | 1.23천 | 1.23K | 1,230 | 일본어는 千 단위를 소수점과 함께 사용하지 않는다 |
| 12,300 | 1.23만 | 12.3K | 1.23 万 | |
| 123,000 | 12.3만 | 123K | 12.3 万 | |
| 1,230,000 | 123만 | 1.23M | 123 万 | |
| 12,300,000 | 1,230만 | 12.3M | 1,230 万 | |
| 123,000,000 | 1.23억 | 123M | 1.23 億 | |

| ICU Locale ID | 거리 | 통화 | 전화번호 | 강조 표기 |

| en_CA | km | $12,345.67 | (AAA) XXX-XXXX | "abc" |

### 구간 표기

한국어는 물결표(~), 영미권은 En Dash(–)를 쓰지만, 지역·언어와 관계없이 Hyphen(-)으로 통일한다.

### 괄호 표기

| 언어 | 예시 | 규칙 |
| --- | --- | --- |
| Korean | 매일 운동을 한다(매일 30분) | 괄호를 앞 단어에 붙여 쓴다 |
| English | Exercise every day (30 min per day) | 괄호 앞에 반드시 띄어쓰기를 넣는다 |
| Japanese | 毎日運動をする(毎日 30 分) | ( )는 한국어와 동일하게 쓴다. 「 」는 괄호 용도로 쓰지 않고 강조·인용에만 사용한다 |

## 텍스트 확장 대비

### 언어별 길이 차이

같은 의미라도 언어에 따라 글자 수가 크게 달라진다.

| 언어 | 텍스트 | 글자수 |
| --- | --- | --- |
| Korean | 저장 | 2자 |
| Japanese | 保存 | 2자 |
| English | Save | 4자 |
| German | Speichern | 9자 |
| French | Sauvegarder | 11자 |

### 예상 확장 비율

한국어 원문이 다른 언어로 번역될 때의 확장 비율. 자세한 배경은 [W3C 국제화 문서](https://www.w3.org/International/articles/article-text-size.en)를 참고한다.

| 한국어 원문 글자수 | 번역 시 확장 공간 |
| --- | --- |
| 10자 이하 | 150% - 250% |
| 11 - 20자 | 130% - 150% |
| 21 - 30자 | 110% - 130% |
| 31 - 50자 | 90% - 110% |
| 51 - 70자 | 80% - 90% |
| 71자 이상 | 80% |

### 레이아웃 적용

- **여유 공간 확보** — 버튼·레이블 등에 긴 번역문이 들어갈 수 있으므로 고정 너비 대신 콘텐츠 기반 크기와 충분한 여유 공간으로 설계한다.
- **줄바꿈 대응** — 긴 번역문의 줄바꿈(wrap)을 허용하거나, 잘림이 필요한 영역은 말줄임 규칙을 정의한다.
- **동적 텍스트 점검** — 지역명·카테고리명 등 길이가 가변적인 텍스트가 들어가는 영역은 긴 값 기준으로 레이아웃 반응성을 점검한다.
