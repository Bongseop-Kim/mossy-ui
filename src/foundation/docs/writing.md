# Writing

일관된 UI 텍스트 작성을 위한 글쓰기 가이드.

## 원칙 참조

이 문서는 [voice-and-tone](./voice-and-tone.md)의 원칙·톤을 문장 단위 규칙으로 구체화한다. 화법·톤의 방향 판단은 voice-and-tone을 따르고, 실제 텍스트 작성·수정은 이 문서를 따른다.

## 단어 선택

1. **익숙한 단어를 사용한다** — 기술 용어·한자어는 이해를 방해한다.
   - Do: 상대방과 대화할 수 없어요. / Don't: 상대방과 대화가 불가능합니다.
   - Do: 동네인증을 할 수 없는 위치예요. / Don't: 동네인증 가능한 위치가 아니에요.
2. **축약어·은어·속어·유행어를 쓰지 않는다** — 사용자들이 줄여 부르더라도 정식 명칭을 쓴다.
   - Do: 끌어올리기는 매일 5회까지 할 수 있어요. / Don't: 끌올은 하루 최대 5회까지 가능합니다.
3. **아라비아 숫자를 사용한다**.
   - Do: 포인트 1개를 보냈어요. / Don't: 포인트 한 개를 보냈어요.
4. **기능의 이름보다 목적을 전달한다**.
   - Do: 보리엄마님이 참외죠아님의 댓글을 좋아해요. / Don't: 보리엄마님이 참외죠아님의 댓글에 좋아요를 눌렀어요.
   - Do: 채팅으로 거래하기 / Don't: 채팅하기

## 문장 구성

5. **긍정문을 사용한다** — 같은 내용이라면 긍정문이 더 잘 읽힌다.
   - Do: 닉네임은 한 달에 한 번만 변경할 수 있어요. / Don't: 한 달에 한 번 이상 닉네임을 변경할 수 없어요.
6. **능동문을 사용한다** — 단, 의미 전달이 더 잘 되면 피동문을 허용한다. 이중피동은 금지.
   - Do: 보리엄마님에게만 보이는 메시지입니다. / Don't: 보리엄마님에게만 보여지는 메시지입니다.
   - 자동 발송이고 사용자가 조심해야 하는 메시지라면 '~요' 대신 '~니다'로 무게를 싣는다.
7. **존칭어를 최소화한다** — 꼭 필요할 때만 사용한다. 사용자 이름을 부를 때는 소리내어 읽어보고 판단한다.
   - Do: 최대 2개의 글을 등록할 수 있어요. / Don't: 최대 2개의 글을 등록하실 수 있어요.
   - Do: 혹시 자전거를 찾고 있나요? / Don't: 혹시 자전거를 찾고 계신가요?
8. **데이터 변화보다 사용자의 행위를 표현한다** — '처리', '완료'는 시스템 관점의 말이다.
   - Do: 거래 후기를 보냈어요. / Don't: 거래 후기 작성을 완료했어요.
   - Do: 게시글 모두 2일 뒤에 숨겨질 거예요. / Don't: 게시물은 이틀 후에 숨김 처리돼요.
9. **하나의 목적에 집중한다** — 부가 설명은 최소화한다. 문장이 길어지면 문장 하나에 하나의 내용만 담고 분리한다.

## 맥락과 감정

10. **진심을 담아 사려깊게 쓴다** — 사용자의 상황과 감정에 와닿게 쓴다.
    - Do: 잠깐만요, 혹시 지금 대화가 불쾌하지는 않으셨나요? 상대방이 거래와 관련 없는 대화를 시도하면 신고해주세요! / Don't: 혹시 상대방이 이상한 대화를 유도하나요?
    - Do: 거래 약속을 깜박하지는 않으셨나요? 약속을 잘 지키는 따뜻한 이웃이 되어보세요. / Don't: 혹시 약속을 자꾸 잊는다면 거래 약속 알림을 사용해보는 건 어때요?
11. **에러 메시지에는 해결 방법을 포함한다** — 장애 상황·기술 용어를 노출하지 않는다.
    - Do: 죄송합니다. 일시적으로 서비스를 사용할 수 없어요. 잠시 후 다시 시도해주세요. / Don't: 서버 에러, unknown error
12. **지역사회의 이야기를 담는다** — 사용자의 동네 이름 등 지역 맥락을 활용한다.
    - Do: 지금 역삼동 근처 주민들과 중고 직거래를 시작해보세요. 내가 쓰지 않는 물건이 누군가에게는 필요한 물건일 수 있어요!
13. **느낌표는 꼭 필요한 순간에만 쓴다** — 반복되면 의미를 잃는다.

## 표기

- **띄어쓰기** — 기능명·서비스명·상태값 자체를 의미할 때는 붙여 쓴다.
  - Do: \[예약중]으로 바꿔보세요. (상태값) / Don't: \[예약 중]으로 바꿔보세요.
  - Do: 예약 중일 때는 채팅할 수 없어요. (일반 서술) / Don't: 예약중일 때는 채팅할 수 없어요.
- **로케일별 표기** — 괄호·강조 부호·구간 등 로케일별 표기 형식은 [international-design](./international-design.md)을 따른다.
- **마침표** — 평서문·명령문 끝에 사용한다. 단, 다음에는 사용하지 않는다.
  - 메인 타이틀 영역 문구
  - 큰 글씨(20pt 이상) 문구
  - 버튼, 메뉴, 라벨 문구
  - 버튼에서 문장 + 긍정/부정 감탄사(네, 아니요)가 있다면 쉼표를 넣는다.
