mossy-ui는 React Native 기반 디자인 시스템입니다. Expo UI는 네이티브 UI 이점이 필요한 컴포넌트에서 선택적으로 사용합니다.

- [컴포넌트 parity](/components/)에서 Seed Design 참고 구현 대비 Mossy 구현 상태를 확인한다.
- [디자인 토큰](/design-tokens/)에서 Props 타입의 `ScopedColor*`, `Dimension`, `Radius` 표기를 Mossy 토큰 값으로 해석하는 규칙을 확인한다.
- 각 컴포넌트 페이지의 `Props` 섹션에서 Seed props와 Mossy 대응 상태를 관리한다.
